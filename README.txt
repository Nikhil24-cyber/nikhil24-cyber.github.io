# Nikhil Bangal - Portfolio Website

## Files
- index.html - portfolio structure/content
- style.css - responsive dark modern design
- script.js - mobile menu, scroll animations, contact form
- resume.pdf - add your actual resume here

## How to run
1. Keep all files in the same folder.
2. Add your resume as `resume.pdf`.
3. Open `index.html` in a browser.

## Important customization
Before publishing, replace:
- `your.email@example.com` with your real email.
- `https://www.linkedin.com/` with your actual LinkedIn profile.
- The placeholder project GitHub links with the actual repository links.
- Project descriptions/details as needed.
